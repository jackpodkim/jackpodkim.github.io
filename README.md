# jackpodkim.github.io

My personal résumé page, served through **GitHub Pages**.

- `index.html` holds both language versions: the English block (`data-l="en"`) and the Korean block (`data-l="ko"`). Edit the text there.
- `style.css` has the layout, the light and dark colours, and the print layout used by the "Save as PDF" button (two A4 pages per language).
- `js/main.js` switches the language. It reads `?lang=en` or `?lang=ko` from the URL first, then the last choice made on the device, then the browser language.

Direct links: <https://jackpodkim.github.io/?lang=en> and <https://jackpodkim.github.io/?lang=ko>.
